# Viewer verification plan: Amendment 1 (17 Oct 2026; committed before governed run 2)

## Reason
Governed run 1 (code `019c930`; recorded as found in `51b9914`, `run1/RUN1_FINDINGS.md`) passed every frozen check.
Visual inspection nevertheless found **F1**: the ribbon of a highlighted residue showed the molecule colour, because
the separate highlight-coloured cartoon that `viewer.py` added was not visible. None of the frozen checks V0-V12 could
detect this, since V5 reads the representation list and V9 is satisfied by the ball-and-stick atoms.

`viewer.py` was fixed in `7131025`, with regression tests in `tests/test_viewer_highlight_colour.py`:
- the highlighted residues are coloured inside the molecule's single cartoon, by a MolViewSpec colour node with a
  selector;
- the coincident cartoon was removed.

Run 1 and its results stay unchanged in the record as the result for code `019c930`.

## Changes to the harness
1. **`render.js`**
   - Records the colour-theme parameters in full. They were truncated to 200 characters, which would break the parse
     of the multi-layer theme Mol* builds for colour nodes with selectors.
   - Adds two screenshots per snapshot, with every ball-and-stick representation hidden through Mol*'s state:
     - `ribbon`: the snapshot re-applied, camera as loaded;
     - `ribbonrna`: the RNA-focus camera, when that component exists.
   - Records the number of hidden representations (`ball_and_stick_hidden`).
   - Everything else is unchanged.
2. **`check_pages.py`**
   - `colour_layers()` parses a representation's colour theme. It accepts `uniform`, or `mvs-multilayer` built
     only from uniform layers whose selection is `all` or a strict merge of `atom-groups(auth_asym_id = X,
     auth_seq_id = N)` terms. Anything else is refused.
   - **V4** checks the cartoon colour layers of the `Protein` and `Nucleic` components exactly.
     - Pages with `"cartoon_layers": true` (written after the fix) must have:
       - the molecule colour over all residues;
       - when the molecule has highlights, exactly one further layer in the highlight colour whose residue set
         equals the expected highlight set.
     - Pages without the flag keep the run-1 meaning: one uniform molecule colour.
   - **V9** is unchanged in meaning: it is evaluated on the three original views only (`loaded`, `overview`,
     `rnafocus`).
   - **V13 (new)**: in the ribbon views, the highlight colour of each molecule with highlights reaches >= 100 px in
     at least one ribbon view. The number of hidden ball-and-stick representations must equal the number of highlight
     components.
3. **`pages_a1.json`**: the six run-1 pages, regenerated by `regen_a1.sh` with the fixed `viewer.py` into new folders
   (`<run-1 folder>_a1`), with the same arguments, and flagged `"cartoon_layers": true`. The demo projects, analyses,
   contact records and groupings are those of run 1, unchanged.
4. **Unchanged:** `run_all.sh`, all other checks, the visual-inspection protocol and the pass rule.
   - For run 2, the full-resolution subset adds the `ribbon` view of each image already in the subset for
     `loaded`.
