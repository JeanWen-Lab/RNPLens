# Qualification scripts for 0.4 development

`grouping/` holds the scripts used to qualify binding-proposal grouping during 0.4 development. Their results are in
`records/grouping/`. The scripts are kept unchanged as part of that record. They check that they run against the
development version they qualified (`0.4.0.dev0`), so they refuse to run under the 0.4.0 release by design.
