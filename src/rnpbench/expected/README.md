Expected outputs for the toolkit example regressions. They were generated on 2026-10-10 on the reference platform (karyon, Linux x86-64) by the ORIGINAL standalone implementations: the RNPBench Predict 1.0.0 source tree, and the RNPBench-Diagnose 0.2.1 source tree with the development host's own `score_decomp`. Each ran in a fresh CPython 3.11.17 venv (`GENERATION_ENVIRONMENT_pip_freeze.txt`). The examples directory path is normalised to `<EXAMPLES>`; Report's `wall_s` and `environment` are removed. The comparison rules are in `../profiles/toolkit_example_regression_profile_v1.json`, which was frozen before these files were generated.

Files: `report_7K9D_result.json` and `report_7K9D_contacts_by_output.json` (the two JSON files Report writes) and `diagnose_7K9D_report.json`, all from the same original runs. The contacts file was added to the expected set after qualification run 1, because the run-1 self-test harness compared Report's in-memory result rather than the files Report writes. It comes from the same original run; no expected value was regenerated.
