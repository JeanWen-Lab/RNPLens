## Summary of bundled scientific data

- **Engine-generated prediction files.** The 22 Boltz-2 coordinate files and 6 per-model confidence JSON files
  were generated by the RNPLens authors with Boltz-2 2.2.1 from public wwPDB sequences. Boltz-2's code and model
  weights are released under the MIT licence, which places no conditions on generated outputs. The multiple
  sequence alignments used to generate them are not redistributed. `examples/DATA_PROVENANCE.tsv` records the
  command, inputs, checksum and attribution of every bundled file; please cite Boltz-2 when reusing these files.
- **Reference disagreement distributions.** The files in `src/rnpbench_diagnose/reference/` contain only
  numerical summaries computed by the RNPLens authors: per-target median pairwise RMSD disagreement values with
  public PDB identifiers. They contain no coordinates, sequences or engine output. `cohortP_disagreement.tsv` is
  derived from Boltz-2 predictions, and `cohortE_disagreement.tsv` from predictions by Boltz-2, Chai-1, RF3 and
  RoseTTAFold2NA. NOTICE, Part B records the licence of each engine.
- **Experimental structures.** These are wwPDB depositions under CC0 1.0, with their primary citations recorded.
- **Scope of the MIT licence.** The licence covers the RNPLens source code only. It does not extend to third-party
  datasets or to the outputs of other prediction engines.
