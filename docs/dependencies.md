## Data in this repository

All structure files in the repository are either Boltz-2 predictions made for the study or copies of wwPDB
entries; no output of any other engine is included. Terms were read from the upstream licence files on 2026-10-13 and re-checked on 2026-10-29.
This is a factual record, not legal advice. The file-by-file manifest, with each file's SHA-256, origin, PDB entry
and primary citation, engine and settings, input sequences, processing and attribution, is
[examples/DATA_PROVENANCE.tsv](../examples/DATA_PROVENANCE.tsv).

| files | content | terms | status |
|---|---|---|---|
| `examples/`, `src/rnpbench/examples/`, `src/rnpbench_report/selftest_data/`, predictions in `src/rnpbench_evaluate/fixtures/` | Boltz-2 predictions (boltz 2.2.1) of PDB 7K9D, 4I67, 2JEA, 4PMI and 6E4P, and the per-model confidence files of 7K9D, generated by the study's authors | Boltz-2 code and weights: MIT licence, which places no restriction on outputs | redistributed under the RNPLens MIT licence; please also cite Boltz-2 |
| `examples/reference_based/7K9D_reference.cif`, references in `src/rnpbench_evaluate/fixtures/` | wwPDB entries 7K9D, 4I67, 2JEA, 4PMI, 6E4P (some trimmed) | CC0 1.0 | redistributable |
| `src/rnpbench_diagnose/reference/` | per-target median pairwise disagreement values (numbers only; no coordinates) from the study's development cohorts | derived from predictions by Boltz-2 (MIT), Chai-1 (chai_lab 0.6.1; Apache-2.0 for code and weights), RF3 (rc-foundry 0.2.0; BSD-3-Clause for code and weights) and RoseTTAFold2NA (MIT code; the weights carry no separate terms in its repository). AlphaFold 3 is excluded (`REFERENCE.json`) | no term of these engines restricts publishing derived numerical summaries |
| `src/rnpbench_evaluate/fixtures/*.json` | fixture rules and selection records | name the internal AlphaFold 3, Chai-1, RF2NA and RF3 fixtures by rule text, identifier and checksum only | no coordinates or scores of those outputs |

The internal regression fixtures built from AlphaFold 3, Chai-1, RF2NA and RF3 outputs are **not** distributed and
were never committed to this repository's history. AlphaFold 3 outputs in particular remain excluded: their terms
restrict use and redistribution.
