# Code availability

The RNPLens source code, documentation, tests, bundled example data and reproducibility records are in the GitHub
repository https://github.com/JeanWen-Lab/RNPLens under the MIT licence (Copyright (c) 2026 The RNPLens authors).

| item | value |
|---|---|
| Version | RNPLens 0.4.1 (Git tag `v0.4.1`; the first public release was 0.4.0, tag `v0.4.0`); optional RNPLens Assistant 0.1.1 |
| Source commit | the commit that the tag `v0.4.1` identifies (`git rev-parse v0.4.1^{commit}`) |
| Platforms | Linux x86-64 and macOS arm64, CPython 3.10–3.12; no GPU, web server or language-model account is needed |
| Optional Assistant | experimental; runs with the user's own Codex (ChatGPT) sign-in and makes no call to a separately billed API |
| Archive and DOI | none issued yet |
| Bundled data | provenance and terms in [example_data_provenance.md](example_data_provenance.md) and `examples/DATA_PROVENANCE.tsv` |

The study's benchmark dataset is not part of this repository; see
[paper_reproducibility.md](paper_reproducibility.md).
